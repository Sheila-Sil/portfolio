01 — about
WHO is this

Half classroom, half codebase.

Sheila is a sophomore at Seven Lakes High School who started coding young, and decided the most useful thing she could do with it was hand it to someone younger. In July 2024 she launched SSC (Sheila's Coding Course), a self-run program for students aged 7–11 that starts in Scratch and works up through HTML, CSS, and JavaScript, with lessons rebuilt around however each kid actually learns.

She's since taken that same energy to TheCoderSchool as a Code Coach. Outside the (real and virtual) classroom, she's active in Girls Who Code, NHS, CSHS, the Technology Student Association, and the Tech Entrepreneurship Club.

02 — the curriculum

The path she teaches — and still walks.

Every SSC lesson follows the same route Sheila built her own skills on. It's a real sequence, not a slide deck; and the route is still growing.

01

Scratch

Where every SSC student starts: drag-and-drop logic, loops, and first sprites — building intuition for how programs think before syntax gets involved.

02

HTML · CSS · JavaScript

From blocks to real code — structuring pages, styling them, then making them interactive. This is also where Sheila's own projects, like Oak Pine Community Hub, began.

03

Java · Python · AI

Backed by Oracle Java Foundations, IBM's Java for Beginners, and an IBM introduction to AI — the layer where logic gets more serious.
